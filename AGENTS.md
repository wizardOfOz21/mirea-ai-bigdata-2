# Системы ИИ и большие данные — 2 семестр

## Материалы

- `exam/framing/questions.pdf` — вопросы к зачёту.

- `information/open/datasets/` — семь подтверждённых публичных датасетов. Авторство, источники, лицензии и изменения данных — в `information/open/datasets/SOURCES.md`; лицензии данных сохраняются отдельно от лицензии собственного кода.

- `exam/delivery/_src/ai-gen-answers.md` и `exam/delivery/ai-gen-answers.pdf` — ответы. Ссылки на слайды обозначены «📍 ЛN сл. M», дополнения — **[доп.]**, ответы без опоры на слайды — ⚠️.
- `exam/delivery/_src/questions-by-lecture.md` и `exam/delivery/questions-by-lecture.pdf` — вопросы, сгруппированные по лекциям.

- `exam/delivery/handwritten-answers.pdf` — конспекты из 19 фотографий. Исходные JPEG удалены; снимки сохранены в PDF.

- `exam/delivery/handwritten-answers-tex.pdf` — набранная версия конспектов; LaTeX-исходник — `exam/delivery/_src/handwritten-answers-tex.tex`. Сборка из `_src/`: `tectonic --outdir .. handwritten-answers-tex.tex`.

## Организация материалов

Для материалов одной категории использовать одинаковые имена папок с обеих сторон: датасеты — `datasets/`. Не создавать пустые зеркальные категории. В `open/` переносить только согласованные материалы. В публичных инструкциях не описывать состав закрытых материалов.

## ИИ-индексы

`_ai-index/` нужен для быстрого поиска и доступа к содержанию материалов, которые агенту неудобно читать напрямую: презентаций, сканов, больших документов. Это вспомогательное представление данных, близкое по назначению к индексу БД: извлечённый текст, OCR, карта разделов или указатели на конкретные страницы и слайды.

Для небольших файлов, которые агент может легко прочитать целиком, индексы не создавать. Простые списки файлов и размеров индексами не считаются. Не создавать `_ai-index/` заранее или ради симметрии папок. Индекс хранить рядом с исходными материалами, сохраняя их категорию доступа; указывать источник и привязку к страницам, слайдам или разделам.

## Конспекты

- Рабочие конспекты и диаграммы для подготовки к зачёту сохранять в `exam/working/`: `<Тема>.md`, без номера лекции в имени. Готовые материалы — в `exam/delivery/`, их исходники — в `exam/delivery/_src/`.
- После каждой правки конспекта пересобирать соответствующий PDF: пользователь проверяет результат по PDF.
- Брать только ту лекцию, которую назвал пользователь.
- Заголовок конспекта — на английском. В значках-плашках использовать английские аббревиатуры (AI, ML); Data Science и Big Data писать полностью. Новые обозначения — по указанию пользователя.
